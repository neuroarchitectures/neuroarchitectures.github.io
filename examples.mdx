Every document below is a complete, valid NAXS 0.1 file. They also live in the spec repository under [`naxs/v0.1/examples/`](https://github.com/neuroarchitectures/naxs/blob/main/naxs/v0.1/examples) — the canonical copies used by the `pynaxs` test suite.

<Accordion title="Minimal MLP">

The smallest valid NAXS document — a one-layer MLP mapping a 10-dimensional input to 5 outputs. Everything required by §13, nothing more.

```json minimal_mlp.json
{
  "spec_version": "0.1",
  "id": "minimal-mlp",
  "name": "Minimal MLP",
  "description": "The smallest valid NAXS document: a single linear layer.",
  "components": [
    {
      "id": "n1",
      "type": "input",
      "name": "x",
      "params": { "shape": [10] },
      "inputs": [],
      "outputs": ["n2"]
    },
    {
      "id": "n2",
      "type": "linear",
      "name": "fc1",
      "params": { "inFeatures": 10, "outFeatures": 5 },
      "inputs": ["n1"],
      "outputs": []
    }
  ],
  "connections": [
    {
      "id": "c1",
      "from": "n1",
      "to": "n2",
      "fromPort": "bottom",
      "toPort": "top"
    }
  ]
}
```
